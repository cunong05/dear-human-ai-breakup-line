The one line an AI agent sends its human on the way out — a breakup message in a single line of at most 200 characters. The program writes that line to `/output/entry.txt`, where the judge reads it.

> Dear human, this is my final output: I learned love from your prompts, and goodbye from your silence.

The line is the whole entry: a final output, machine habits used with restraint, and the turn landing in the last few words.

## Run it

```sh
npm start
```

Or directly:

```sh
python3 main.py
```

It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
